# 校招工作台（2027 秋招投递管理）

一个可在线访问的校招投递管理 Web 应用，两个核心页面：

- **校招企业库**：按行业分类（互联网 / 制造业 / 手机厂 / 车企 / 银行 / 央国企 / 通信 / 事务所）汇总开放 2027 届校招的企业，可搜索、按类型筛选、直达官方投递入口。
- **投递工作台**：跟踪你投递的每一家企业与岗位，一键更新投递状态，展示招聘漏斗（待投 → 已投 → 测评 → 笔试 → 面试 → Offer/淘汰），支持按企业 / 岗位 / 地点 / 是否已投 / 状态筛选。

## 技术说明
- 纯前端单页应用（`index.html`，自包含、无外部依赖），部署于 GitHub Pages。
- 数据存于浏览器本地（localStorage），通过 **CSV 导入 / 导出** 与飞书「2027届秋招投递管理系统」多维表格同步；飞书表为唯一主账本。
- 种子数据来自用户的飞书投递跟踪表（45 条）。

## 数据同步
1. 在飞书表维护记录后 → 导出 CSV → 应用内「导入 CSV」读取。
2. 或在本应用内修改后 →「导出 CSV」→ 回填飞书表。

## 本地运行
直接双击打开 `index.html`，或用任意静态服务器：
```
python -m http.server 8000
```
访问 http://localhost:8000
